# Retail Sales Analysis Dashboard | Power BI

## 📊 Project Overview

An interactive Retail Sales Analysis Dashboard developed using Power BI to analyze sales, profit, orders, product performance, customer segments, regions, and profit margins.

The project demonstrates an end-to-end data analytics workflow including data preparation, data modeling, DAX calculations, and interactive dashboard development.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Modeling
- Data Visualization

## 📁 Dataset

The analysis uses retail sales data containing information about:

- Orders
- Customers
- Products
- Categories
- Sub-Categories
- Regions
- Sales
- Profit
- Quantity
- Discounts
- Returns

## 📌 Dashboard Pages

### 1. Executive Overview

Provides an overall view of business performance using:

- Total Sales
- Total Profit
- Total Orders
- Profit Margin %
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Profit by Category
- Profit by Region
- Profit by Sub-Category

### 2. Segment Analysis

Analyzes performance across customer segments:

- Sales by Segment
- Orders by Segment
- Profit by Segment
- Profit Margin % by Segment

### 3. Product & Profit Analysis

Provides detailed product-level analysis:

- Sales by Sub-Category
- Top 10 Products by Sales
- Profit by Sub-Category
- Profit Margin % by Category

## 📈 Key Insights

- Technology generated the highest sales and profit among the major categories.
- The South region recorded the highest sales among the regions.
- Consumer was the largest customer segment by sales and order volume.
- Office Supplies recorded the highest category-level profit margin.
- Accessories was the highest-selling sub-category.
- Overall profit margin was approximately 11.23%.

## 🧮 DAX Measures

Key measures created in Power BI include:

- Total Sales
- Total Profit
- Total Orders
- Profit Margin %

## 🔗 Data Model

The Power BI model contains three main tables:

- Calendar
- Products
- Sales_Data

Relationships were created between the dimension tables and Sales_Data to support accurate analysis.
